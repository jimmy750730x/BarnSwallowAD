> **接住負擔，留住福氣 ── 台灣街角的人鳥共生實踐**  
> 台北市野鳥學會 (WBST) × Virtual Market 2026 Winter (VKET) 公益推廣活動單頁網站。

---

## 📖 專案簡介 (Overview)

本專案為 **台北市野鳥學會 (Wild Bird Society of Taipei, WBST)** 與林保署合作推動之「燕你好好板」公民計畫宣傳頁面，同時作為 **Virtual Market 2026 Winter** 參展之 3D 家燕模型免費領取導流頁。

### 🌟 核心特色
- **零建置負擔 (Zero-build Architecture)**：採用 Vue 3 CDN + Tailwind CSS CDN，開箱即用、隨開即跑。
- **全方位多語言 (i18n)**：內建 **中文 (CN)**、**日文 (JP)**、**英文 (EN)** 三語即時切換。
- **故事化滿版篇章 (Storyboard Experience)**：以六幕整頁式篇章導覽，從台灣騎樓特色、人鳥衝突、燕板解方到 3D 虛擬世界的傳承。
- **動態色彩與流暢交互**：隨滾動進度變換大地自然色系背景，右側懸浮導覽點即時反饋瀏覽進度。

## 🚀 GitHub Pages 啟用步驟

1. 進入此 Repository 頁面，點選頂部 **Settings**。
2. 左側選單點選 **Pages**。
3. 在 **Build and deployment** > **Branch** 下：
   - 選擇分支：`main`
   - 選擇資料夾：`/(root)`
   - 點擊 **Save**。
4. 等待 1~2 分鐘，上方即會產生正式的網站公開網址：  
   `https://jimmy750730x.github.io/BarnSwallowAD/`
